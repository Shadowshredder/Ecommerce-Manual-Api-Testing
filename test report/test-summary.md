\# E-Commerce Web Application – Test Summary



\## 1. Project Overview



This project demonstrates end-to-end QA testing of an e-commerce web application, covering functional testing, API testing, defect reporting, and SQL-based data validation.



The testing scope includes the major user flows:



\* User Login

\* Product and Cart Management

\* Checkout

\* REST API validation

\* Database/data validation

\* Defect lifecycle management



\## 2. Testing Scope



| Module           | Testing Type       |

| ---------------- | ------------------ |

| Login            | Functional Testing |

| Cart             | Functional Testing |

| Checkout         | Functional Testing |

| REST APIs        | API Testing        |

| Application Data | SQL Validation     |

| Defects          | Bug Tracking       |

\### Bug Lifecycle



\*\*New → Assigned → Open → Fixed → Retest → Closed\*\*



If a defect fails during retesting:



\*\*Retest → Reopened → Fixed → Retest → Closed\*\*
